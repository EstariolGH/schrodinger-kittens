# Котята Шрёдингера 🐈

Код к статье «Котята Шрёдингера: как я разводил квантовых котов на процессорах IBM».

Кот и кошка сидят в одной квантовой коробке с одним атомом: распался атом — умирает кот, не распался — кошка. Если оба живы, рождается котёнок. Программа `cats.py` собирает такую коробку из кубитов, открывает её тысячу раз и рисует гистограмму: кто сколько раз выжил и сколько родилось котят. Запускать можно на симуляторе прямо на своём компьютере или на **настоящем квантовом процессоре IBM** — бесплатно.

Ниже — пошаговая инструкция для тех, кто ни разу не ставил Python. Если у вас Windows, можно вообще обойтись без неё: [установка в два щелчка](#самый-простой-путь-windows-в-два-щелчка). Если вы уже умеете ставить Python-проекты, хватит раздела [«Быстрый старт»](#быстрый-старт).

## Самый простой путь (Windows): в два щелчка

1. Скачайте проект: зелёная кнопка **Code → Download ZIP** вверху страницы. Распакуйте архив в папку **без русских букв и пробелов в пути**, например `C:\quantum-cats`.
2. Дважды щёлкните **`install.bat`**. Он сам:
   - найдёт Python, а если его нет — поставит Python 3.13 (через winget или скачав установщик с python.org);
   - создаст виртуальное окружение `.venv` в папке проекта;
   - установит Qiskit и всё остальное (несколько минут) и проверит, что всё работает.
3. Дважды щёлкните **`start.bat`** — откроется меню:

   ```
   1. Симулятор: общий атом - котят нет
   2. Симулятор: у каждого свой атом
   3. Модель шумного чипа IBM, без интернета
   4. Сохранить ключ IBM - один раз
   5. Настоящий квантовый компьютер IBM
   ```

Для пунктов 4 и 5 нужен бесплатный аккаунт IBM Quantum и ключ — как их получить, написано в [шаге 6](#шаг-6-регистрация-в-ibm-quantum-и-ключ-ibm). Положите скачанный `apikey.json` в папку проекта и выберите пункт 4.

> Windows может показать синее окно «Windows защитила ваш компьютер» — это стандартное предупреждение для любых скачанных `.bat`. Нажмите *Подробнее → Выполнить в любом случае*. Если хотите сначала посмотреть, что делает файл, откройте его Блокнотом: там обычный текст с комментариями.

Если `install.bat` по какой-то причине не справился — пройдите шаги ниже вручную, там разобраны все типичные проблемы.

## Быстрый старт

```bash
git clone https://github.com/EstariolGH/schrodinger-kittens.git
cd schrodinger-kittens
python -m venv .venv
.venv\Scripts\activate            # macOS / Linux: source .venv/bin/activate
pip install -r requirements.txt

python cats.py                    # симулятор: котят нет
python cats.py --mode independent # у каждого свой атом: котята есть

python save_key.py                # один раз: сохранить ключ IBM
python cats.py --backend ibm --shots 4000
```

## Шаг 1. Установить Python

Нужен Python **3.11, 3.12 или 3.13** (автор проверял на 3.13).

### Windows

**Вариант А — через сайт (проще всего).**

1. Откройте [python.org/downloads](https://www.python.org/downloads/) и скачайте установщик для Windows (жёлтая кнопка *Download Python 3.x*).
2. Запустите его и **обязательно поставьте галочку «Add python.exe to PATH»** внизу первого окна. Без неё команда `python` не будет находиться.
3. Нажмите *Install Now* и дождитесь конца установки.

**Вариант Б — одной командой** (для тех, у кого есть winget — он встроен в Windows 10/11). Откройте терминал и выполните:

```powershell
winget install Python.Python.3.13
```

**Проверка.** Закройте все окна терминала и откройте новое (старые окна не знают, что Python появился). Выполните:

```powershell
python --version
```

Должно появиться что-то вроде `Python 3.13.x`.

> **Если вместо этого открылся Microsoft Store** или пишет, что `python` не найден:
> - попробуйте команду `py --version` — это «запускатор» Python, он ставится вместе с ним. Тогда везде ниже пишите `py` вместо `python`;
> - или отключите заглушку Windows: *Параметры → Приложения → Дополнительные параметры приложений → Псевдонимы выполнения приложений* и выключите там `python.exe` и `python3.exe`.

### macOS

Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/) или, если есть Homebrew, выполните `brew install python@3.13`. Проверка: `python3 --version`. На macOS и Linux везде ниже пишите `python3` вместо `python`.

### Linux

Обычно Python уже есть. Проверьте `python3 --version`. Если версия старше 3.11 или нет модуля venv — поставьте через пакетный менеджер, например для Ubuntu/Debian:

```bash
sudo apt install python3 python3-venv python3-pip
```

## Шаг 4. Создать виртуальное окружение и поставить библиотеки

**Виртуальное окружение** — это отдельная папка `.venv` внутри проекта, куда ставятся библиотеки только для него. Так вы ничего не сломаете в системе, а удалить всё можно, просто стерев папку проекта.

**1. Создать окружение** (один раз):

```bash
python -m venv .venv
```

**2. Активировать его** — это нужно делать **каждый раз**, когда открываете новое окно терминала:

| Где | Команда |
|---|---|
| Windows, командная строка (cmd) | `.venv\Scripts\activate.bat` |
| Windows, PowerShell / Терминал | `.venv\Scripts\Activate.ps1` |
| macOS / Linux | `source .venv/bin/activate` |

После активации в начале строки появится `(.venv)` — значит, всё получилось.

> **PowerShell ругается «выполнение сценариев отключено в этой системе»?** Выполните один раз
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, ответьте `Y` и повторите активацию. Или просто пользуйтесь командной строкой `cmd` — там такой проблемы нет.

**3. Поставить библиотеки** (один раз, при активированном окружении):

```bash
pip install -r requirements.txt
```

Скачается несколько сотен мегабайт: Qiskit (библиотека IBM для квантовых вычислений), симулятор Qiskit Aer, клиент для облака IBM и matplotlib для графиков. Это займёт несколько минут.

## Шаг 5. Первый запуск на симуляторе

```bash
python cats.py
```

Программа:

1. нарисует схему коробки прямо в терминале;
2. «подглядит» в закрытую коробку — покажет все варианты и их вероятности (так можно только на симуляторе);
3. откроет коробку 1000 раз и выведет, что выпало;
4. сохранит гистограмму в `cats_histogram.png` и откроет её в отдельном окне.

Котят будет **ноль**. А теперь дайте каждому коту свой атом:

```bash
python cats.py --mode independent
```

Котята появятся примерно в четверти коробок. Почему так — рассказано в статье.

Есть ещё модель настоящего шумного чипа IBM, она работает без интернета и без очереди:

```bash
python cats.py --backend fake
```

## Шаг 6. Регистрация в IBM Quantum и ключ IBM

У IBM есть бесплатный план **Open**: до **10 минут работы квантового процессора за скользящие 28 дней**. Одна наша коробка на 4000 запусков занимает несколько секунд, так что хватит надолго.

### 6.1. Регистрация

1. Откройте [quantum.cloud.ibm.com](https://quantum.cloud.ibm.com) и зарегистрируйтесь (создайте **IBMid**): почта, пароль, код подтверждения из письма.
2. Войдите в платформу. Если она предложит создать **instance** (рабочее пространство), выберите бесплатный план **Open**. Instance с планом Open создаётся только в регионе **us-east** — регион переключается в выпадающем списке вверху страницы.

### 6.2. Создать API-ключ

1. На главной странице платформы (*Home / Dashboard*) найдите блок **API key** и нажмите **Create**.
2. Придумайте ключу любое имя и подтвердите.
3. Ключ покажут **один раз**. Скопируйте его — или, если в окне есть кнопка **Download**, скачайте файл `apikey.json`.

> ⚠️ **Ключ — это как пароль.** С ним кто угодно сможет тратить ваши минуты. Не вставляйте его в код, не выкладывайте в репозиторий и не показывайте на скриншотах. Если ключ всё-таки утёк — удалите его в кабинете IBM и создайте новый.

### 6.3. Сохранить ключ на компьютере

Ключ **не нужно вписывать в `cats.py`**. Его один раз сохраняет специальный скрипт, а дальше Qiskit находит его сам.

**Если вы скачали `apikey.json`** — положите его в папку проекта, рядом с `save_key.py`, и выполните:

```bash
python save_key.py
```

**Если вы просто скопировали ключ** — выполните ту же команду. Скрипт не найдёт файл и попросит вставить ключ: нажмите Ctrl+V (или правую кнопку мыши) и Enter. Символы при вводе **не отображаются** — это нормально, так сделано специально.

Если всё в порядке, скрипт напишет «Готово!» и покажет список доступных вам квантовых процессоров (`ibm_kingston`, `ibm_marrakesh` и т. п.).

Ключ сохраняется в служебный файл Qiskit в вашей домашней папке (`C:\Users\<вы>\.qiskit\qiskit-ibm.json`, на macOS/Linux — `~/.qiskit/qiskit-ibm.json`). После этого **удалите `apikey.json` из папки проекта** — он больше не нужен. На всякий случай он уже прописан в `.gitignore`, так что git его не заберёт.

Поменялся ключ? Просто запустите `python save_key.py` ещё раз — старый перезапишется.

## Шаг 7. Запуск на настоящем квантовом компьютере

```bash
python cats.py --backend ibm --shots 4000
```

Программа сама выберет **самый свободный** процессор, переложит схему под его устройство и поставит задачу в очередь. Она напечатает имя процессора и **Job ID** — номер задачи.

Дальше нужно подождать. Очередь бывает от минуты до пары часов, окно можно не закрывать: когда процессор освободится, результат придёт сам, и откроется гистограмма. Статус задачи видно на сайте, в разделе **Workloads**.

Хотите конкретный процессор — укажите его:

```bash
python cats.py --backend ibm --chip ibm_kingston --shots 4000
```

Сколько котят-призраков родится у вас? Пишите в комментариях к статье — у нас там конкурс 🙂

## Все параметры cats.py

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `--mode shared` | общий атом на двоих (котят не бывает) | ✔ |
| `--mode independent` | у каждого кота свой атом | |
| `--backend sim` | идеальный симулятор на вашем компьютере | ✔ |
| `--backend fake` | модель шумного чипа IBM (FakeTorino), без интернета | |
| `--backend ibm` | настоящий квантовый процессор IBM | |
| `--chip ИМЯ` | конкретный процессор IBM, например `ibm_kingston` | самый свободный |
| `--shots N` | сколько раз открыть коробку | 1000 |
| `--theta ГРАДУСЫ` | вероятность распада атома: 90 — это 50/50 | 90 |
| `--out ФАЙЛ` | куда сохранить гистограмму | `cats_histogram.png` |
| `--no-show` | не открывать окно с графиком | |

Подсказка по всем параметрам: `python cats.py --help`.

## Если что-то пошло не так

**`python` не найден / открывается Microsoft Store.**
Закройте и заново откройте терминал после установки Python. Не помогло — смотрите подсказку в [шаге 1](#шаг-1-установить-python): команда `py` или отключение псевдонимов.

**`ModuleNotFoundError: No module named 'qiskit'` (или `matplotlib`).**
Почти всегда это значит, что не активировано виртуальное окружение: в начале строки нет `(.venv)`. Активируйте его ([шаг 4](#шаг-4-создать-виртуальное-окружение-и-поставить-библиотеки)). Можно и без активации — запустить Python прямо из окружения: `.venv\Scripts\python.exe cats.py`.

**`Ключ IBM не найден. Сначала один раз выполните: python save_key.py`.**
Значит, ключ ещё не сохранён — выполните [шаг 6.3](#63-сохранить-ключ-на-компьютере).

**`save_key.py` пишет «подключиться не удалось» / «Unable to retrieve instances».**
Проверьте, что ключ скопирован целиком, без пробелов по краям, и что у вас есть instance с планом Open ([шаг 6.1](#61-регистрация)). Создайте новый ключ и запустите `python save_key.py` ещё раз.

**`AccountAlreadyExistsError`.**
Так бывает, если вызывать `save_account` вручную без `overwrite=True`. Скрипт `save_key.py` эту проблему обходит — просто используйте его.

**В терминале «кракозябры» вместо русских букв.**
Программы сами переключают вывод в UTF-8, но в старой командной строке может не хватить шрифта. Откройте *Терминал Windows* — там всё отображается правильно.

**Окно с графиком не открылось.**
Картинка всё равно сохранена в `cats_histogram.png` в папке проекта.

**Задача на IBM висит в очереди очень долго.**
Это нормально для бесплатного плана. Можно закрыть программу (Ctrl+C): задача останется в очереди, а результат будет виден на сайте в разделе **Workloads**.
